# The personal viewing edit

The release video is an approximately 86-second author edit of the rendered ESCAPEMENT extension.
The code and rebuild instructions produce the approximately 78-second edit with the upstream manifest-based mix.
They reproduce the project picture and procedural edit before the changes listed here, not this final viewing file.

## Music

- Track: **Wall of Sound**. Made with Suno by **djkix93** ([public profile](https://suno.com/@djkix93)).
- Prompt and selection: **Ai.chemyst**.
- Generation setup reported by the author: **Suno free plan, v6 mini, default settings**.
- The author confirms the track was obtained through Suno's own download/export.
- Intended use: a **personal, non-monetised showcase**.

The generation prompt was:

> Mid-90s post-grunge/alternative, heavy drop-tuned rhythm guitars shifting from clean analog-modulated verse ambience to double- and quad-layered, high-gain mid-saturated chorus walls, locked-in bass and tightly controlled acoustic drums with crisp snare transients, compressed kick shells, and direct overheads; punchy mix-bus processing, dense wall-of-sound master with high dynamic contrast; intimate dry verse vocals opening into heavily doubled, upper-mid-carved belt vocals; soft verses and loud choruses.

This records the prompt and settings; it does not promise an identical result from a new generation.

## Manual finishing in InShot

Ai.chemyst lightly edited the soundtrack, slowed the crash section, and added heartbeat and boom sounds from
InShot's library. These finishing changes are not scripted in this repo. The rest of the picture is from the
rendered project. Separate music and effect source files are not distributed here.
